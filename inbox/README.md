# Inbox: David's drop folder

Put anything here for the AI to process: screenshots, notes, numbers, recordings notes. Any file name and format is fine; a subfolder per topic or session helps (`inbox/2026-11-20 Katalina/`).

The AI then makes site pictures from your screenshots with `tools/inbox_images.py` (cropped, saved as `.webp` without quality loss), saves the numbers into `data/`, notes into `docs/`, moves the screenshots it used into `sources/`, and clears what it processed from here.

Nothing here is published on the site. The repository is public, though, so anyone can see these files on GitHub: don't put anything private here.
