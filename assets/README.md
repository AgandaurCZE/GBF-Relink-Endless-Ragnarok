# Pictures and fonts the site shows

Everything here is published. Only pictures and fonts; anything else goes to `data/`, `sources/` or `docs/` (the checks enforce this).

| Folder | For |
|---|---|
| `characters/` | Character portraits and art |
| `weapons/` | Weapon pictures |
| `sigils/` | Sigil icons |
| `items/` | Materials, consumables and other items |
| `enemies/` | Bosses and enemies |
| `icons/` | Small icons: elements, roles, stats, menu |
| `ui/` | Site pictures: favicon, logo, share image |
| `fonts/` | Web fonts (`.woff2`) |

A new kind of picture gets its own folder; add it to this table.

- `.webp` preferred (also `.png`, `.jpg`, `.svg`, `.gif`); no file over 5 MB.
- Lowercase names with hyphens, named after what they show: `characters/katalina.webp`, `sigils/war-elemental.webp`.
- Picture quality comes before file size.
